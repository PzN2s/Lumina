✦ Lumina ✦

A TUI system cleaner & monitor for Linux. Written entirely by hand — zero AI-generated code.

Features:
- Clean system caches (APT, DNF, Pacman, Zypper, XBPS, APK, Nix, Gentoo)
- Live monitoring: CPU, RAM, Swap, Disk, GPU, processes
- 15 color themes
- Works on all major distros

Install:
git clone https://github.com/PzN2s/Lumina
cd Lumina
go build -o lumina .
sudo ./lumina

Install system-wide:
sudo cp lumina /usr/local/bin/ && lumina
